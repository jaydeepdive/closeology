Closeology Claims API

Every active mineral claim in Canada, its details, its location, and a map overlay you can drop onto any map. Free, public, rebuilt daily from each province's and territory's official registry.

No key, no sign-up. Every endpoint sends Access-Control-Allow-Origin: *, so you can call it straight from a browser on any domain, or from a server.

Overlay the claims on your map

Add closeology-claims.js and make one call with the map library you already use. Clicking a claim opens its details.

Each call returns a handle with a remove() method. Not using one of these libraries? Use the raw formats below; they're standard.

Look up a claim

const claim = await CloseologyClaims.getClaim("YT", "YC88074");
// { id, jurisdiction, holder, name, issued, expiry, area_ha, lon, lat, bbox, tile, record_url }
// null if it isn't an active claim today

Without the helper: claims are split into small files per jurisdiction. Fetch api/v1/claim/{jurisdiction}/{shard}.json, where shard = fnv1a32(id) % lookup_shards (32-bit FNV-1a over the UTF-8 bytes of the claim number; lookup_shards is in jurisdictions.json). The file is an object keyed by claim number.

Claims in an area

const fc = await CloseologyClaims.getClaimsInBBox([-81.6, 48.3, -81.0, 48.7]);   // [west, south, east, north]
// GeoJSON FeatureCollection, polygons with the fields below

Raw formats & endpoints

Base URL: https://jaydeepdive.github.io/closeology/

EndpointWhat it is
api/v1/index.jsonManifest: endpoints, field schema, counts, build date.
api/v1/jurisdictions.jsonPer jurisdiction: claim count, bounding box, source registry, field coverage, lookup shard count, official-record URL template.
api/v1/claims.pmtilesVector tiles (PMTiles v3, Mapbox Vector Tile format). Layer claims: every claim polygon, zooms 9–11 (overzoom beyond). Layer coverage: one point per ~5 km cell with staked ground, zooms 0–8, property n = claims in the cell. Works with MapLibre, OpenLayers (ol-pmtiles), Leaflet (protomaps-leaflet), deck.gl, and QGIS / GDAL.
api/v1/claims.style.jsonReady-made MapLibre source + layer definitions for the vector tiles.
claimtiles/index.json
claimtiles/{ix}_{iy}.geojson		GeoJSON tiles on a 0.5° grid: ix = floor(lon / 0.5), iy = floor(lat / 0.5). Full-precision polygons (~1 m). Only keys in index.json exist. A claim crossing a tile edge appears in each tile it touches. Short property keys: c id, j jurisdiction, o holder, n name, i issued, e expiry, a area_ha.
api/v1/claim/{jur}/{shard}.jsonSingle-claim lookup (see above).
api/v1/claims/{jur}.csv.gzBulk CSV per jurisdiction.
claim_coverage.geojsonThe coverage points as plain GeoJSON.

Jurisdiction codes: AB BC MB NB NL NS NT NU ON QC SK YT (lower-case in URLs). Coordinates are WGS84 longitude/latitude. Dates are YYYY-MM-DD.

Updates, stability & attribution

Updates. Rebuilt once a day from each jurisdiction's public registry. A claim that lapses disappears from the next build. Check generated in index.json for the build date.

Stability. Everything under /api/v1/ plus the claimtiles keys above is a stable contract. New fields may be added; existing ones won't be renamed or change meaning without a new version (/api/v2/).

Attribution. Please credit "Claims: Canadian mineral tenure registries via Closeology". The underlying records belong to each province and territory; see jurisdictions.json for each source.

Verify before you stake or transact. This is a convenience copy of public registry data and can lag the registry by up to a day. Always confirm a claim's status in the official registry.
